# Medical Document Review Platform

## Overview

An AI-powered Medical Document Review Platform that evaluates medical documents using MedGemma through the Bifrost API.

## Supported Documents

### Prescription

- Prescription Image
- Prescription PDF
- Prescription Text

### X-ray

- X-ray Image
- X-ray Report PDF
- X-ray Report Text

## Tech Stack

### Backend

- FastAPI
- SQLAlchemy
- SQLite
- Alembic

### Frontend

- Next.js
- React
- Tailwind CSS

### AI

- MedGemma
- Bifrost API
